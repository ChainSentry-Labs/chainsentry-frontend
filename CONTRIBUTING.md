# Contributing to chainsentry-frontend

## Setup
```
npm install
npm run lint
npm run build
npm run dev
```

## Before opening a PR
- Run lint and build and make sure they pass.
- Keep the PR scoped to one issue; reference it with `Closes #N`.
- Update README.md if you changed a page's behavior.

## Related repos
- chainsentry-backend — API this dashboard fetches from
- chainsentry-contract — the on-chain source of truth
